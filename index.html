Undo 실험실

아래 뇌 영상에 편집을 몇 번 해 본 뒤 되돌리기를 눌러 보세요. 편집할 때마다 편집 전 이미지가 스택에 push되고, 되돌리기는 꼭대기를 pop합니다. 그래서 가장 마지막에 한 편집부터 거꾸로 취소됩니다(LIFO).

편집 도구

Undo 스택 0

    Redo 스택 0

      성능 비교

      스택이 없다면 되돌리기를 할 때마다 원본에서 나머지 편집을 전부 다시 계산해야 합니다. 같은 편집 20개를 해 둔 상태에서 마지막 하나를 되돌리는 시간을 이 기기에서 직접 재 봅니다. 대신 스택은 편집 하나마다 스냅샷(약 0.59 MB)을 저장하므로, 시간을 메모리로 바꾼 셈입니다.
